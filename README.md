# Система учёта посетителей организации

## Назначение

Консольная программа регистрирует одно посещение организации и определяет, можно ли выдать посетителю допуск. Решение помогает сотруднику на стойке регистрации проверить срок действия пропуска и может ли принимающий сотрудник встретиться с посетителем сейчас.

## Целевая аудитория

Сотрудники ресепшена, службы безопасности и администраторы организации.

## Предметная область

Организация принимает внешних посетителей. Для посещения нужен действующий пропуск и принимающий сотрудник, который готов принять посетителя. Результатом работы является карточка зарегистрированного посещения с решением о допуске.

## Основные сущности

- **Посетитель** — человек, пришедший в организацию; для него указываются ФИО и документ.
- **Сотрудник** — принимающий работник организации.
- **Пропуск** — документ с номером и датой окончания действия.
- **Посещение** — факт обращения посетителя в организацию в определённое время и с указанной целью.

## Основные функции

- пошаговый ввод данных одного посетителя, сотрудника и пропуска с проверкой каждого поля;
- регистрация цели и времени посещения;
- проверка срока действия пропуска;
- проверка возможности принимающего сотрудника встретиться с посетителем;
- вывод решения о допуске и карточки посещения.

## Запуск

Требуется Python 3. Запустите в корневой папке проекта:

```powershell
python main.py
```

Дата окончания пропуска вводится в формате `ДД.ММ.ГГГГ`. На вопрос о возможности сотрудника принять посетителя введите `да` или `нет`. При ошибке программа сразу объяснит, что введено неверно, и повторит только текущий вопрос.

## План развития

На следующих этапах планируется:

- разработка веб-приложения на Django;
- подключение базы данных для хранения посетителей, сотрудников, пропусков и посещений;
- реализация учётных записей и ролей пользователей;
- создание функций поиска, изменения и удаления данных;
- разработка REST API;
- контейнеризация приложения в Docker;
- настройка CI/CD.

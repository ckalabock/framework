# ПР5 — Django, HTTP и основы веб-разработки

## Выполнено

Создан Django-проект `visitor_project` и приложение `webapp`. Корневой URLconf подключает маршруты приложения через `include()`. Реализованы view-функции главной страницы, списков и карточек посетителей, сотрудников, пропусков и посещений. Динамические URL используют `<int:...>`, отсутствующая запись возвращает 404.

Веб-часть использует классы ПР3 и загрузчики `storage.py`: источник данных — `data/*.json`. На ПР5 намеренно не используются ORM, миграции, Django Forms и база SQLite — это темы следующих практик. Консольное приложение `python main.py` сохранено.

Добавлены HTML-страницы, CSS и Bootstrap CDN. Все представления возвращают `render(request, template, context)`, поэтому HTTP-запрос проходит цепочку `visitor_project/urls.py` → `webapp/urls.py` → view → шаблон → `HttpResponse`.

## Проверка

```powershell
python manage.py check
python manage.py runserver
python -m pytest -v
python -m flake8 .
```

Откройте `http://127.0.0.1:8000/`. Для демонстрации покажите `manage.py`, `visitor_project/settings.py`, `visitor_project/urls.py`, `webapp/urls.py`, `webapp/views.py` и страницы `/visitors/`, `/visits/1/`, `/visits/999999/`.

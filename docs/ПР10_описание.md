# ПР10 — Django ORM и административная панель

## Выполнено

- подключены стандартные приложения Django Admin, авторизация, сессии и сообщения;
- добавлен маршрут `/admin/`;
- зарегистрированы модели `Visitor`, `Employee`, `AccessPass` и `Visit`;
- для админ-панели настроены столбцы, поиск, фильтры и сортировка;
- настроены inline-формы: пропуска и посещения отображаются внутри карточки посетителя, посещения — внутри карточки сотрудника;
- для связанных полей включён поиск через `autocomplete_fields`;
- сохранены ORM-модели ПР9, миграции и команда `seed_demo`.

## Запуск

```powershell
python manage.py migrate
python manage.py seed_demo
python manage.py createsuperuser
python manage.py runserver
```

Откройте `http://127.0.0.1:8000/admin/`, войдите под созданным суперпользователем и покажите разделы посетителей, сотрудников, пропусков и посещений.

## Проверка

```powershell
python manage.py check
python manage.py showmigrations
python manage.py test webapp
python -m pytest -v
python -m flake8 . --exclude=.venv
```

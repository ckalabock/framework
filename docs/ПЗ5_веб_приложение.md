# Практическое занятие №5 — веб-приложение

## Что требовалось

Задание требовало реализовать backend и frontend монолитного веб-приложения, бизнес-логику, API, пользовательский интерфейс, интеграцию клиента и сервера, а также предусмотреть безопасность, тестирование и подготовку к развёртыванию.

## Что сделано

- Выбран стек Django + SQLite + Django Templates + CSS.
- Создан backend в `visitor_project/` и `webapp/`.
- Описаны модели посетителя, сотрудника, пропуска и посещения.
- Перенесены бизнес-правила: действующий пропуск, доступность сотрудника и запрет дубликатов активных посещений.
- Созданы HTML-страницы входа, панели управления и форм создания сущностей.
- Добавлен JSON API: `/api/visitors/` и `/api/visits/`.
- Добавлена авторизация через Django и CSRF-защита всех POST-форм.
- Валидация данных выполняется Django Forms.

## Проверка

```powershell
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Откройте `http://127.0.0.1:8000/login/`, войдите созданным пользователем, добавьте посетителя, сотрудника, пропуск и посещение. Затем откройте `/api/visitors/` и `/api/visits/`.

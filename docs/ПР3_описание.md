# ПР3 — переход к объектно-ориентированной модели

## Что требовала практика

ПР3 требовала сохранить проект ПР2, представить основные сущности классами, реализовать `__init__`, `__str__`, методы объектов и их взаимодействие. JSON должен загружаться в объекты и сохранять объекты обратно в JSON. Тесты, обработка ошибок, аннотации типов, `flake8` и документация должны остаться актуальными.

## Что добавлено и переработано

- В `models.py` добавлены классы `Visitor`, `Employee`, `AccessPass` и `Visit`.
- Каждый класс имеет конструктор, атрибуты и строковое представление `__str__`.
- В `Visitor` добавлен метод `matches_name()` для поиска по ФИО.
- В `Employee` добавлен метод `can_receive_visitor()`.
- В `AccessPass` добавлен метод `is_valid_on()` для проверки срока действия.
- В `Visit` добавлены методы `is_allowed()` и `cancel()`.
- Посещение связывает реальные объекты посетителя, сотрудника и пропуска, а не только отдельные значения.
- `storage.py` восстанавливает объекты из JSON и при сохранении преобразует объекты обратно в словари.
- Тесты проверяют методы классов, разрешение допуска, отмену посещения и защиту от дублирующей активной записи.

## Что сохранилось из ПР2

Сохранились модули, JSON-файлы, консольное меню, обработка неверного ввода, тесты и разделение ответственности между файлами. Функции для обработки коллекций остаются обычными функциями, потому что работают со списками объектов целиком, а не с состоянием одного объекта.

## Демонстрация на защите

Покажите классы в `models.py`, создание `Visit`, вызовы `visit.is_allowed()` и `visit.cancel()`, затем запуск тестов и `flake8`.

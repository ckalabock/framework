# Практическое занятие №6 — интеграция, безопасность и тестирование

## Что требовалось

Задание продолжает разработку веб-приложения: backend и frontend должны работать через API, данные должны проверяться, доступ — контролироваться, а приложение — пройти модульную и интеграционную проверку и быть подготовлено к развёртыванию.

## Что сделано

- HTML-интерфейс связан с серверными Django views через формы и маршруты.
- JSON API возвращает сведения о посетителях и посещениях для клиентских сценариев.
- Для закрытых страниц и API используется `login_required`.
- Для POST-запросов используется CSRF-токен.
- Ограничения БД защищают уникальность документов и номеров пропусков, а также запрещают дубли активных посещений.
- Данные проверяются формами, а ошибки нарушения уникальности обрабатываются без аварийного завершения.
- SQLite применяется как локальная база; `runserver` используется для демонстрации, а WSGI-конфигурация подготовлена для развёртывания.

## Проверка

```powershell
python manage.py check
python -m pytest -v
python -m flake8 .
```

В браузере проверьте вход без авторизации, создание записей через формы, JSON API и отмену посещения. Ожидаемый результат — `System check identified no issues`, все тесты проходят, а `flake8` не выводит замечаний.

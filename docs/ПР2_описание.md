# ПР2 — продолжение проекта: коллекции, функции, циклы и JSON

## Что требовала практика

ПР2 требовала переработать сценарий ПР1 в функциональную консольную программу. В проекте должны быть коллекции, циклы, функции, несколько модулей, обработка исключений, JSON-хранение, аннотации типов, тесты `pytest`, проверка `flake8` и актуальный `README.md`.

## Что добавлено

- Коллекции для работы с несколькими посетителями, сотрудниками, пропусками и посещениями.
- Консольное меню с операциями просмотра, добавления, поиска, сортировки, регистрации и отмены посещений.
- Модули `visitors.py`, `employees.py`, `passes.py`, `visits.py`, `storage.py` и `utils.py`.
- Безопасный ввод: неверные числа, даты и ответы не завершают программу с ошибкой, а запрашиваются повторно.
- Хранение данных в `data/visitors.json`, `data/employees.json`, `data/passes.json` и `data/visits.json`.
- Загрузка и сохранение JSON через контекстные менеджеры `with open(...)`.
- Автоматические тесты в каталоге `tests/` и зависимости в `requirements.txt`.

## Что изменилось относительно ПР1

В ПР1 программа обрабатывала только одного посетителя за запуск. После ПР2 она поддерживает набор записей, выполняет поиск посетителя по части ФИО, выводит посетителей в сортированном виде, создаёт посещения на выбранные даты и сохраняет результат между запусками.

## Что проверить перед защитой

```powershell
python main.py
pytest -v
flake8 .
```

Нужно также вручную показать работу пунктов меню и поставить breakpoint в функции `has_active_visit()` либо `create_visit()` для пошаговой отладки.

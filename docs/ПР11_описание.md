# ПР11 — формы Django

## Выполнено

- создана обычная форма `VisitFilterForm` на основе `forms.Form`;
- фильтры посещений передаются через GET: дата, посетитель, сотрудник и статус;
- создана `VisitForm` на основе `ModelForm` для создания и редактирования посещений;
- настроены labels, widgets, CSS-классы и подсказка поля цели;
- добавлена встроенная и пользовательская валидация: прошедшая дата, принадлежность и срок пропуска, доступность сотрудника, конфликт активных посещений;
- ошибки отдельных полей и общие ошибки выводятся в шаблоне;
- создание и редактирование обрабатывают GET и POST, успешное сохранение завершается redirect;
- отмена посещения выполняется POST-формой со сменой статуса, запись из базы не удаляется;
- все POST-формы защищены `{% csrf_token %}`;
- добавлены автоматические тесты фильтра, валидации и отмены.

## Проверка

```powershell
python manage.py check
python manage.py test webapp
python -m pytest -v
python -m flake8 . --exclude=.venv
python manage.py runserver
```

В браузере открыть `/visits/`, проверить GET-фильтры, создание, ошибки валидации, редактирование и отмену посещения.

Загрузка изображений не добавлена, поскольку предметная область учёта посещений её не требует. Методичка допускает этот пункт только если возможность предусмотрена проектом.

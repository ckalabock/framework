# ПР6 — шаблоны Django

## Выполнено

Добавлен общий `templates/base.html` с `{% load static %}`, Bootstrap, CSS и JavaScript. Дочерние страницы используют `{% extends %}` и переопределяют блоки `title` и `content`. Навигация, карточка посетителя и статус посещения вынесены в переиспользуемые фрагменты через `{% include %}`.

В шаблонах показаны контекст, обращение к атрибутам объектов, циклы `{% for %}`, `{% empty %}`, условия `{% if %}`, фильтры `length`, `default`, `date`, `capfirst`, именованные URL с namespace `webapp` и динамические ссылки через `{% url %}`. Добавлен собственный `templates/404.html`. Статические ресурсы находятся в `static/webapp/css`, `static/webapp/js` и `static/webapp/images`.

Данные по-прежнему берутся из JSON, HTML не формируется строками Python, ORM и формы не подключены.

## Проверка

```powershell
python manage.py check
python manage.py test webapp
python -m pytest -v
python -m flake8 .
```

В браузере проверьте главную, списки и карточки, затем откройте несуществующую запись. В DevTools → Network убедитесь, что CSS, JS и SVG загружаются со статических URL.
